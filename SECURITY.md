# Security Policy

## Supported versions

Current main branch is supported for security updates.

## Reporting a vulnerability

Please report vulnerabilities privately before public disclosure.

Contact: **info@amirahco.us**

Include:
- affected file(s) and function(s)
- reproduction steps
- expected vs actual behavior
- impact assessment

## Security notes

- This project is local-first and file-based.
- Avoid storing secrets in memory nodes unless explicitly intended.
- Keep runtime data directories outside public repos.
