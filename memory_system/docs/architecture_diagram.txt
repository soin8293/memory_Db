## Flow During User Request

1. User Message
   ↓
2. Policy Analysis (build_runtime_policy.sh)
   ↓
3. Memory Retrieval (memory_search + memory_get)
   ↓
4. Context Assembly (MEMORY.md + relevant nodes)
   ↓
5. AI Model Processing
   ↓
6. Memory Updates (if needed)
   ↓
7. Response Generation
