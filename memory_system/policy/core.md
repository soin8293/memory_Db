# Core Memory Policy

## Fundamental Rules

### Privacy & Security
- Never expose private user information outside secure contexts
- Encrypt sensitive data in memory nodes
- Prevent memory leakage between different user sessions

### Memory Hygiene
- Keep MEMORY.md under 2000 characters (executive summary only)
- Use daily files for raw logs, curated memory for durable facts
- Regularly review and clean outdated information
- Prefer structured nodes over unstructured text

### Information Integrity
- Verify information before adding to permanent memory
- Maintain provenance data for all memory nodes
- Flag uncertain or contradictory information
- Preserve original context when possible

### Performance
- Optimize for fast retrieval of common queries
- Minimize memory injection size during AI sessions
- Use indexing for frequently accessed information
- Implement lazy loading where appropriate

### Continuity
- Maintain backward compatibility for memory formats
- Preserve user preferences and identity information
- Ensure smooth transitions during memory system updates
- Provide migration paths for deprecated formats
